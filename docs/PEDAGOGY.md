# Base pedagógica

Principios que guían el diseño:
- **Input comprensible (i+1):** se aprende con mensajes algo por encima del nivel actual (Krashen, 1982/1985).
- **Producción:** además de input, hay que producir lenguaje (hipótesis de output de Swain, 1985). Por eso cada lección termina escribiendo.
- **Repaso espaciado y recuerdo activo:** intervalos crecientes y obligar a recordar. Hoy: 1, 3, 7, 16 y 35 días. Pendiente: FSRS.
- **Frecuencia:** priorizar el vocabulario más frecuente.
- **Tiempo realista:** Cambridge English estima ~180–200 h guiadas acumuladas para A2, ~350–400 para B1, ~500–600 para B2 y ~700–800 para C1 (https://support.cambridgeenglish.org/hc/en-gb/articles/202838506-Guided-learning-hours). Son guías, no promesas.

Limitación: estos principios provienen de resúmenes divulgativos y de la teoría general. Antes de publicar conviene que un especialista valide el currículo y cite estudios primarios.
